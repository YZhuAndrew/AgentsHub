# AgentsHub 0.7.2 Release Record

## Release

- Version: `0.7.2`
- Tag: `v0.7.2`
- Date: 2026-08-13
- Channel: Stable (fork)
- Status: Published

## Summary

AgentsHub 0.7.2 adds an opt-in persistent status-bar (menu-bar / tray) icon so
AgentsHub stays reachable from the menu bar even while the window is open.

## Contents

### Features

- **Persistent status-bar icon toggle** (`feat(desktop)`): a new "Persistent
  Status Bar Icon" setting (default off) creates the tray on app launch
  regardless of window state; off preserves the prior minimize-to-tray-only
  behavior. The tray exists whenever `showTrayIcon || minimizeToTray`, creation
  is idempotent, and the toggle takes effect live. Plumbed through the shared
  Settings type, renderer store, preload, a main DB reader, and a General
  settings toggle (7 locales). See
  `spec/changes/active/persistent-tray-icon/`.

### Version Bumps

- Root, Desktop, CLI, self-hosted Web, Cloudflare Worker, and Mobile manifests
  report `0.7.2`, including Expo app metadata. `CLI_VERSION` and the CLI
  `--version` test updated to match.

## Distribution

- Desktop: macOS arm64 + Windows x64 + Linux builds produced by the `release.yml`
  workflow via `workflow_dispatch` on `v0.7.2` (**unsigned**; signing/R2 secrets
  not configured in this fork, so R2 mirror sync is skipped).
- Release created as DRAFT and promoted to latest via
  `gh release edit v0.7.2 --draft=false --latest`. The desktop auto-updater then
  serves 0.7.2.

## Known Caveats

- Users still on ≤0.7.0 cannot auto-upgrade through the in-app flow (the
  pre-upgrade backup threw on symlinks). Install 0.7.1+ manually over the top
  once; future auto-upgrades work.
- macOS builds are unsigned; on a fresh install Gatekeeper may block first
  launch (`sudo xattr -rd com.apple.quarantine /Applications/AgentsHub.app`).
- R2 mirror is not populated (R2 secrets not configured).
