# AgentsHub 0.8.0 Release Record

## Release

- Version: `0.8.0`
- Tag: `v0.8.0`
- Date: 2026-08-14
- Channel: Stable (fork)
- Status: Published

## Summary

AgentsHub 0.8.0 is a feature release covering the 49 commits shipped since
`v0.7.2`: MCP project and Pi configuration workflows (#200/#201/#202), the
completed agent management workbench (unified provider/model surfaces, Pi
provider import and model tests, quota/session polish), file-first canonical
storage authority, on-demand prompt list projection, the image-generation
workbench redesign, window geometry persistence, and Markdown skill file
preview. It also routes unsigned macOS direct installs to manual DMG updates
and folds the historical `0.6.0-beta.1` preview line into the stable
narrative.

## Contents

### Features

- **MCP project and Pi configuration workflows** (`fix(mcp)` #200/#201/#202):
  merged global/project target projection in My MCP, Pi-compatible MCP
  configuration writes, direct/reference environment values with
  target-aware interpolation, reference health warnings, and literal-value
  redaction across IPC, backup, CLI sync, and target results. See
  `spec/changes/archive/2026/08/2026-08-06-mcp-issues-200-202-implementation/`.
- **Agent management workbench completion** (`feat(agent)` series): one
  provider/model workbench shell across generic profiles, native config, and
  Pi; PromptHub provider import into Pi `models.json`/`auth.json` with
  main-only credentials, atomic writes, and two-file rollback; Pi model
  catalog editing with quota-aware model tests; Agent Pet management; native
  quota popover with Kimi renewal; conversation pagination/continuation and
  history index caching. See
  `spec/changes/active/agent-management-workbench/`.
- **Expanded verified rules and MCP targets** (`feat(agent)`): Pi-compatible
  MCP discovery, project-scoped Cursor/Qoder rules, verified OpenClaw, Qoder,
  Grok, Antigravity, and Reasonix MCP projections.
- **Image-generation workbench redesign** (`feat(desktop)`): single-artwork
  review focus, pinned settings/history panels, explicit reference-image
  selection, large drag area, local image path encoding fix. See
  `spec/changes/active/desktop-image-generation-workbench/`.
- **File-first canonical storage authority** (`feat(storage)`): versioned
  canonical files own durable Prompt/Skill/Rule/MCP/Plugin/Agent/Generation
  resources with rebuildable SQLite catalogs, renderer persistence migration,
  journaled recovery, portable snapshots, and immutable schema conversion.
- **Window geometry persistence** (`feat(desktop)`): main-window
  width/height/x/y/maximized persisted to the settings table and restored on
  launch with display-visibility validation and size clamping. See
  `spec/changes/active/restore-window-state/`.
- **Markdown skill file preview** (`feat(desktop)`): `.md`/`.mdx` files in the
  Skill detail Files tab render as formatted preview (frontmatter stripped)
  with an Edit toggle. See
  `spec/changes/active/skill-file-markdown-preview/`.

### Performance

- **Prompt list projection** (`perf(prompt)`): PromptSummary list projection
  plus DB/IPC/store detail caches; full prompt content loads on demand. See
  `spec/changes/active/desktop-prompt-list-projection/`.

### Fixes

- **Unsigned macOS direct-install update routing** (`fix(desktop)`): darwin
  direct installs keep update detection but route installation to a manual
  DMG download; Win32/Linux/Homebrew unchanged. See
  `spec/changes/active/update-channel-hardening/`.
- **Atomic MCP target projection** (`fix(mcp)`): temp-write/atomic-replace
  with rollback; no persistent backup files left in Agent/project
  directories.
- **Config-file edit isolation** (`fix(agent)`): reads/writes bounded to
  platform-declared paths; per-source inventory/cache isolation; unsaved-edit
  confirmation when switching Agents.
- **Rule-conflict scrolling** (`fix(rules)`): single focusable scroll region
  with managed-vs-external labels. See
  `spec/changes/active/rules-managed-copies/`.
- **Hardened recovery publication** (`fix(storage)`): journaled, rollback-safe
  recovery publication preserving canonical startup state.
- **Startup language persistence** (`fix(desktop)`): explicit saved language
  no longer overwritten by the renderer default.
- **Dev-server survival** (`fix(desktop)`): serialized/coalesced main-process
  rebuilds no longer kill the Vite dev server.

### Maintenance

- Linux CI verification and E2E secret storage repairs; bounded verification

- macOS unsigned-fork policy made the single source of truth

- `0.6.0-beta.1` historical prerelease published (manual-testing artifact

### Version Bumps

- Desktop: macOS arm64 + Windows x64 + Linux builds produced by the
  `release.yml` workflow (unsigned; signing/R2 secrets not configured in this
  fork, so R2 mirror sync is skipped).
- Planned publication: push tag `v0.8.0`, then promote the draft release via
  `gh release edit v0.8.0 --draft=false --latest` so the desktop
  auto-updater serves 0.8.0.
- Release notes must carry the verbatim macOS 安全说明 notice (emitted by
  `release.yml`).

## Known Caveats

- Users still on ≤0.7.0 cannot auto-upgrade through the in-app flow (the
  pre-upgrade backup threw on symlinks); install 0.7.1+ manually over the top
  once. macOS direct installs route updates to manual DMG download because
  the artifacts are unsigned.
- macOS builds are unsigned; on a fresh install Gatekeeper may block first
  launch (`sudo xattr -rd com.apple.quarantine /Applications/AgentsHub.app`).
- R2 mirror is not populated (R2 secrets not configured).
