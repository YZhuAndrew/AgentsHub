## Summary

AgentsHub 0.8.2 is a hotfix release repairing two user-reported Skill detail
page defects and superseding v0.8.1 as the latest stable. Published the same
day as v0.8.1; v0.8.1 remains available, and its release notes point users to
0.8.2. Auto-update clients on 0.8.1 receive 0.8.2 through the stable channel
(same-version re-publication cannot reach already-installed 0.8.1 clients, so
the fix ships as 0.8.2).

1. **Skill distribution selection cleared immediately.** Selecting target
   platforms in the detail page distribution panel (or the quick-install
   dialog) was reset to empty moments after clicking, because
   `useSkillPlatform` re-keyed its install-status refresh on the whole skill
   object and every refresh executed `setSelectedPlatforms(new Set())`; any
   store write replacing the skill object, or the mount-time refresh
   resolving after the user started clicking, wiped the selection. Fixed by
   keying the refresh on the skill id, pruning newly-installed ids instead of
   clearing, and resetting only on skill switch or completed batch install.
   See `spec/changes/active/skill-detail-distribution-selection-stability/`.

2. **Preview scroll stutter from a renderer update loop.** With the auto
   safety scan enabled, each scan report save replaced the skill object in
   the store while the scan effect depended on the whole object, producing an
   endless scan → save → rescan loop; unrelated re-renders also re-parsed the
   whole markdown preview. Fixed by primitive-keyed scan dependencies,
   no-op suppression for unchanged safety report saves, and a memoized
   `SkillMarkdown` with stable plugin arrays.
   See `spec/changes/active/skill-detail-distribution-selection-stability/`.

## Contents

### Fixes

- **Skill detail distribution selection stability** (`fix(skill)`
  `skill-detail-distribution-selection-stability`): refresh keyed by skill
  id; routine refreshes prune installed ids from the selection; selection
  resets on skill switch or after batch install.
- **Auto-scan rescan loop and preview render isolation** (`fix(skill)`
  `skill-detail-distribution-selection-stability`): scan effect keyed on
  effective scan inputs, unchanged safety reports keep store object
  identity, `SkillMarkdown` memoized with stable remark/rehype plugins.
