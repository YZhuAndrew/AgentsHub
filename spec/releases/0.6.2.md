# AgentsHub 0.6.2 Release Record

## Release

- Version: `0.6.2`
- Tag: `v0.6.2`
- Date: 2026-08-11
- Channel: Stable (fork)
- Status: Preparation

## Summary

AgentsHub 0.6.2 ships two Skill-management improvements on top of `0.6.1`: an
enhanced default list view for the Skill library, and detailed progress feedback
when installing Skills from a Git repository.

## Contents

### Features

- **Skill list view enhancement** (`feat(desktop)`): the list view is now the
  default Skill library layout (with a one-time persistence migration so
  existing users land on it), rebuilt as a column-header table showing name +
  description, source, author, version, created/updated time, platform status,
  and inline actions. An author filter joins the existing tag filter, and a
  "check all updates" batch action runs per-source fingerprint checks with
  bounded concurrency, aggregated into "update available" badges, with batch
  update for selected skills. The gallery view is retained. See
  `spec/changes/active/skill-list-enhance/`.
- **Git Skill import progress** (`feat(desktop)`): installing Skills from a Git
  repository now reports detailed progress for both the Scan and Import phases —
  phase label, batch counter (`index / total` + skill name), and live
  `git clone --progress` percentage — replacing the single opaque spinner. See
  `spec/changes/active/skill-git-import-progress/`.

### Version Bumps

- Root, Desktop, CLI, self-hosted Web, Cloudflare Worker, and Mobile manifests
  report `0.6.2`, including Expo app metadata. `CLI_VERSION` constant and the
  CLI `--version` test updated to match. Private shared packages retain their
  independent `0.1.0` versions.

## Distribution

- Desktop: macOS arm64 + Windows x64 builds produced by the `release.yml`
  workflow on the `v0.6.2` tag push (DMG + ZIP, **unsigned**). Release artifacts
  are named `AgentsHub-${version}-*` per the electron-builder `productName`.
- Release is created as a **DRAFT** by the workflow and promoted to latest via
  `gh release edit v0.6.2 --draft=false --latest` after the build succeeds.

## Known Caveats

- macOS builds are not Apple Developer-ID signed or notarized (same as 0.6.0 /
  0.6.1). On first launch macOS Gatekeeper may block the app; users can run
  `sudo xattr -rd com.apple.quarantine /Applications/AgentsHub.app`.
- The skill list view default flip is a user-visible behavior change: existing
  users who never chose a layout are migrated to the list view (one-time
  migration); the gallery view remains selectable.

## Verification

- `pnpm lint`: passed.
- `pnpm --filter @prompthub/cli test -- run.test.ts --run`: CLI `--version`
  reports `0.6.2`.
- `pnpm verify:release:quick`: release-impacting quick gate.
- Full `pnpm verify:release` gate and macOS signing are out of scope for this
  fork environment; the `release.yml` workflow performs the build on tag push.

## Rollback

Before publication, revert the version bumps and the feature commits. This
release changes no database schema; the skill list view default migration is a
session/localStorage preference and is harmless to leave in place.
