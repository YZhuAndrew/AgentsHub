# AgentsHub 0.7.1 Release Record

## Release

- Version: `0.7.1`
- Tag: `v0.7.1`
- Date: 2026-08-13
- Channel: Stable (fork)
- Status: Published

## Summary

AgentsHub 0.7.1 is a patch release that fixes an upgrade blocker: the
pre-upgrade data backup aborted on the first symbolic link (e.g. a symlink-mode
Skill install), preventing the upgrade from proceeding.

## Contents

### Fixes

- **Upgrade backup handles symlinks** (`fix(desktop)`): replaced the snapshot
  copy filter that threw on any symlink with one that preserves symlinks
  resolving within the user data directory (faithful, restorable copies of
  internal links such as symlink-installed Skills), skips symlinks escaping the
  directory (keeps the snapshot restorable; the restore path already rejects
  escaping links), and preserves dangling links. Root and link target are
  `realpath`-normalized so macOS `/var` → `/private/var` does not misclassify
  internal links. See `spec/changes/active/fix-upgrade-backup-symlinks/`.

### Version Bumps

- Root, Desktop, CLI, self-hosted Web, Cloudflare Worker, and Mobile manifests
  report `0.7.1`, including Expo app metadata. `CLI_VERSION` and the CLI
  `--version` test updated to match.

## Distribution

- Desktop: macOS arm64 + Windows x64 + Linux builds produced by the `release.yml`
  workflow via `workflow_dispatch` on `v0.7.1` (**unsigned**; signing/R2 secrets
  not configured in this fork, so R2 mirror sync is skipped).
- Release created as DRAFT by the workflow and promoted to latest via
  `gh release edit v0.7.1 --draft=false --latest`. The desktop auto-updater then
  serves 0.7.1.

## Known Caveats

- Users on a version with this bug (≤ 0.7.0) cannot auto-upgrade to 0.7.1
  through the in-app flow, because their installed code still throws at backup
  time. To upgrade: manually install 0.7.1 over the top (bypasses the in-app
  backup), or remove the offending local symlink before auto-upgrading.
- macOS builds are unsigned; on a fresh install Gatekeeper may block first
  launch (`sudo xattr -rd com.apple.quarantine /Applications/AgentsHub.app`).
- R2 mirror is not populated (R2 secrets not configured).
