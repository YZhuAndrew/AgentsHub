# AgentsHub 0.6.1 Release Record

## Release

- Version: `0.6.1`
- Tag: `v0.6.1`
- Date: 2026-08-10
- Channel: Stable (fork)
- Status: Preparation

## Summary

AgentsHub 0.6.1 adds the 千问办公 (QwenWork) built-in agent platform and three
startup-behavior controls for the desktop app. It is a feature release on top of
the first AgentsHub fork release `0.6.0`.

## Contents

### Features

- **QwenWork agent platform** (`feat(desktop)`): built-in `qwenwork` target with
  the `~/.qwenwork` root, a `skills/` convention, and the official green octopus
  mascot icon. Minimal skeleton; deeper MCP/session/provider adapters are
  deferred. See `spec/changes/active/qwenwork-agent-platform-support/`.
- **Startup behavior settings** (`feat(desktop)`): the main window now opens by
  default on launch (`minimizeOnLaunch` default flipped `true → false`); a new
  `startupModule` setting (default `"last"`) chooses which home view opens at
  startup; OS auto-launch (`launchAtStartup`, default off) is reused unchanged.
  See `spec/changes/active/startup-behavior-settings/`.

### Version Bumps

- Root, Desktop, CLI, self-hosted Web, Cloudflare Worker, and Mobile manifests
  report `0.6.1`. `CLI_VERSION` constant and the CLI `--version` test updated to
  match. Private shared packages retain their independent `0.1.0` versions.

## Distribution

- Desktop: macOS arm64 + Windows x64 builds produced by the `release.yml`
  workflow on the `v0.6.1` tag push (DMG + ZIP, **unsigned**).
- The electron-builder `publish` provider still points at the upstream
  `legeling/PromptHub` repo; this is a known follow-up and does not block the
  fork release assets, which are uploaded by the workflow's `gh release` step.

## Known Caveats

- macOS builds are not Apple Developer-ID signed or notarized (same as 0.6.0).
  On first launch macOS Gatekeeper may block the app; users can run
  `sudo xattr -rd com.apple.quarantine /Applications/AgentsHub.app`.
- `minimizeOnLaunch` default flip is a user-visible behavior change: new users
  and users who never toggled it will now see the window on launch instead of
  starting hidden to tray.

## Verification

- Desktop unit tests: `pnpm vitest run` on the touched files passed
  (platform-icon, agent-platform-capabilities, general-settings,
  settings-startup, app-startup-module, i18n-init).
- ESLint: passed on all changed TS files.
- Full `pnpm verify:release` gate and macOS signing are out of scope for this
  fork environment; the `release.yml` workflow performs the build on tag push.

## Rollback

Before publication, revert the version bumps and the feature commits. This
release changes no database schema or user data.
